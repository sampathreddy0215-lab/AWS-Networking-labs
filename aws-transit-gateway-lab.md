# AWS Transit Gateway Lab

## Objective

Learn how AWS Transit Gateway simplifies connectivity between multiple VPCs and on-premises networks.

## Components

- Transit Gateway
- VPC A
- VPC B
- Route Tables
- Security Groups

## Steps

1. Create a Transit Gateway
2. Create VPC Attachments
3. Associate Route Tables
4. Configure Routes
5. Verify Connectivity

## Benefits

- Centralized Routing
- Simplified Management
- Scalable Architecture
- Hybrid Connectivity

## Real-World Use Case

A large enterprise uses Transit Gateway to connect multiple AWS accounts and VPCs while maintaining centralized routing and security policies.
